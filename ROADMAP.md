# Roadmap

## Delivered in 0.1.0

- [x] Essential (default), Lines and Blocks in a fixed dark taskbar capsule.
- [x] Optional weekly indicators and usage-based bar colors.
- [x] Separate provider Details, elapsed-time markers, reset times and labelled forecasts.
- [x] Immediate hover, click-only mode, focus-preserving cards and close-to-tray settings.
- [x] Claude and Codex official-client sign-in with isolated profiles and account reuse.
- [x] Background quota refresh, error handling, freshness and provider identity.
- [x] Ripple from local execution signals; arrows restricted to Details.
- [x] Opt-in Windows startup, tray menu and context-menu exit.
- [x] Per-user setup, portable ZIP, version metadata and uninstall integration cleanup.
- [x] Daily update checks, manual check/install button and SHA-256 verification.
- [x] English installation, account, privacy and release documentation.
- [x] Automated packaging with a strict release-file allowlist.

## Next validation

- [ ] Broader Windows 11 build and taskbar compatibility coverage.
- [ ] Auto-hide, fullscreen, Explorer restart and monitor/DPI transitions.
- [ ] Additional multi-monitor and accessibility testing.
- [ ] Longer-running real-account refresh and rate-limit recovery tests.
- [ ] Publisher code signing.
- [ ] Better official-provider support as usage APIs evolve.

Website/Desktop execution detection is not currently implemented; quota visibility and local activity are different capabilities. Additional providers and account switching are possible future work, without a committed date.
