# Taskcode 0.3.1

Provider logos throughout the app and a fix for intermittent taskbar indicator disappearance.

## Provider logos

- Replace initials with vector logos for Cursor, Antigravity, GLM Coding Plan, Grok, GitHub Copilot, OpenCode Go, Command Code, Qoder and DeepSeek Harness.
- Show the logos in all seven indicator styles, the Manage providers list and provider headers.
- Embed the artwork in the application so it works offline and retains each provider's accent color.

## Indicator stability

- Keep the last verified taskbar measurement through brief UI Automation failures, within the existing four-second freshness limit.
- Continue checking live taskbar/tray bounds and hide the indicator when the layout changes or there is insufficient verified space.
- Avoid reconfiguring the native window when its position and size have not changed.
- Refresh the transparent surface when the indicator becomes visible again.
- Record pause and resume reasons in the bounded local lifecycle log.

## Validation

Windows build, regression tests and installer packaging pass, including transient measurement failure, expiry, recovery and native placement in Embedded and Overlay modes. Provider logos were rendered at 125%, 150% and 200%. A local installer upgrade preserved preferences byte-for-byte; the updated embedded indicator stayed visible throughout a 30-second observation.

Download **Taskcode-Setup-0.3.1-win-x64.exe** for installation or **Taskcode-0.3.1-win-x64.zip** for portable use. Existing users can update from **General > Check for updates**.

Windows 11 x64 and .NET Framework 4.8 are required. The installer remains unsigned; see the [installation guide](https://github.com/angelosc1/taskcode/blob/main/docs/INSTALL.md) for SmartScreen instructions.
