# Taskcode 0.4.0

Animated 3D provider logos and a scrolling taskbar capsule that keeps all enabled providers accessible.

## Provider logos

- All eleven provider marks now have 15% extrusion, softer shading and a diagonal reflection from a consistent light direction.
- Idle logos face forward without reflection. Active logos rotate at three consumption-speed levels; Claude and Codex use local activity and the recent-speed estimates shown in Details.
- Optional providers rotate after measured quota or local-token increases. They stop after an unchanged reading, stale data or disconnect; their polling cadence still applies.
- The Codex mark is slightly larger. Details headers keep the original static marks to avoid animation flicker.
- Windows animation preferences and high-contrast settings remain respected.

## All providers in one capsule

- When enabled providers exceed the verified free taskbar gap, the capsule stops growing and its content scrolls right to left at normal size.
- Hovering or reading Details pauses scrolling. Clicks and Details anchors follow the visible provider; the mouse wheel moves the content manually.
- A spaced separator keeps the last and first providers apart as the sequence repeats.
- Placement still avoids other taskbar controls and requires a usable, freshly verified gap.

## Validation

Windows regression checks cover all eleven providers, all seven styles, weekly on/off, 100% to 200% scaling, scroll wrapping and hit testing, activity transitions, static Details headers and transparent rendering. Temporary animation and sample-data controls have been removed.

Download **Taskcode-Setup-0.4.0-win-x64.exe** for installation or **Taskcode-0.4.0-win-x64.zip** for portable use. Existing users can update from **General > Check for updates**.

Windows 11 x64 and .NET Framework 4.8 are required. The installer remains unsigned; see the [installation guide](https://github.com/angelosc1/taskcode/blob/main/docs/INSTALL.md) for SmartScreen instructions.
