Taskcode now speaks English and Brazilian Portuguese.

- **General > Language** offers **System** (default), **English** and **Português (Brasil)**. System follows the Windows display language, with English fallback.
- Switching languages updates the interface immediately, without reconnecting accounts or restarting Taskcode.
- Settings, provider Details, menus, tooltips and connection/update messages are translated. The installer also supports Brazilian Portuguese.
- Community translations can be contributed through JSON catalogs; new catalogs are discovered automatically. [Translation guide](https://github.com/angelosc1/taskcode/blob/main/locales/README.md) · [Contributing](https://github.com/angelosc1/taskcode/blob/main/CONTRIBUTING.md).

Download **Taskcode-Setup-0.2.0-win-x64.exe** below, or use **General > Check for updates > Install v0.2.0**. Existing account profiles, preferences and Windows startup choice are preserved.

### Windows SmartScreen warning

The installer is unsigned. If **Windows protected your PC** appears, and you downloaded the installer from this official repository and trust it, click **More info**, check the installer filename, then click **Run anyway**. **Unknown publisher** is expected for this unsigned release. You do not need to disable Microsoft Defender or SmartScreen.
