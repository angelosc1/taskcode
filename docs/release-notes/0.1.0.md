Taskcode's first public Windows test release.

- Claude and Codex quota in a dark taskbar capsule.
- Essential (default), Lines and Blocks; optional weekly indicators and usage-based bar colors.
- Separate, non-activating provider Details with elapsed-time markers and labelled usage forecasts.
- Official-client sign-in, isolated account profiles and local execution Ripple.
- Per-user installer, Start menu shortcut, optional Windows startup and portable ZIP.
- General > Check for updates, optional daily checks and checksum-verified installer updates.

**Install:** download `Taskcode-Setup-0.1.0-win-x64.exe` and run it. [Installation and account setup](https://github.com/angelosc1/taskcode/blob/main/docs/INSTALL.md).

**Requirements:** Windows 11 x64, .NET Framework 4.8, and the relevant official CLI. The installer is unsigned.

**Known limitations:** taskbar embedding is experimental across Windows builds; use Overlay if needed. Claude quota checks have a five-minute minimum interval. Local activity detection does not cover the Claude website/Desktop app. Auto-hide, Explorer recovery, fullscreen, multiple monitors and scaling need broader testing.

### Windows SmartScreen warning

The current installer is unsigned. If **Windows protected your PC** appears, and you downloaded the installer from this official repository and trust it, click **More info**, check the installer filename, then click **Run anyway**. **Unknown publisher** is expected for this unsigned release. You do not need to disable Microsoft Defender or SmartScreen.
