Fixes Claude's five-hour session display immediately after reset.

- A fresh reading of 0% without a new reset time now shows **0% used**, **5h available** and **Starts with first request**.
- Waiting does not start a local countdown. The clock follows the provider's next valid reset time, even if rounded usage is still 0%.
- A known reset triggers one fresh quota check instead of waiting for the ordinary five-minute cache interval. Failure and rate-limit cooldowns remain in effect.
- Local execution starting during the waiting state can trigger a bounded recheck. Website/Desktop requests remain limited by provider polling.
- Weekly timing remains independent and follows the provider's supplied reset.

Update through **General > Check for updates > Install v0.1.2**, or download `Taskcode-Setup-0.1.2-win-x64.exe`.
