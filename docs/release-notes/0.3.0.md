# Taskcode 0.3.0

Four new indicator styles, optional Windows providers, shared monitoring controls, and a fix for Details closing immediately.

## Indicator styles

- Add **Donuts**, **Sparkline**, **Dot Matrix** and **Color Strip**, alongside Essential, Lines and Blocks.
- Use the existing weekly switch to show five-hour readings alone or both five-hour and weekly readings.
- Apply optional green/yellow/red consumption colors independently to each meter, ring or chart while retaining provider logo colors.
- Give Donuts smaller rings, balanced padding and centered separators; tighten Sparkline value/chart and weekly-row spacing.
- Fit saved wider styles inside the settings preview immediately when settings open.

Sparkline displays current consumption, change in percentage points, and measured history collected while Taskcode is open. Its bounded in-memory history restarts after quota rollover, corrections, source errors or long gaps. Cached readings never create observations, and a first observation shows a forming history instead of a fabricated trend.

## Providers and connections

- Add optional **Cursor**, **Antigravity**, **GLM Coding Plan**, **Grok**, **GitHub Copilot**, **OpenCode Go**, **Command Code**, **Qoder** and **DeepSeek Harness** monitoring.
- All nine additions are **disabled by default**. Disabled providers do not read credentials, poll, or occupy indicator space.
- Add **Accounts > Manage providers**, including the same monitoring toggle for Claude and Codex. Both remain enabled by default; switching one off hides its indicator and preserves its official login and selected profile.
- Provide official app/CLI sign-in actions, encrypted Windows-user API-key entry where supported, refresh/disconnect controls, and Qoder connector installation.
- Preserve optional-provider server cooldowns across restarts and discard results arriving after disconnection.

Each integration has its own requirements. Antigravity uses its running app's local server. Qoder requires its official SDK connector and CLI login. DeepSeek Harness reports local daily token/session counts with Node.js 24+, without inventing an official quota or dollar cost. Some internal provider endpoints may reject access or change. See [provider setup and limitations](https://github.com/angelosc1/taskcode/blob/v0.3.0/docs/OPTIONAL-PROVIDERS.md).

## Details

- Fix manual Details closing immediately when the appearance preview is hidden or taskbar placement is paused.
- Hover cards still dismiss when the pointer leaves. Explicit clicks and the settings Details action keep cards open until their close button or an outside click.
- Preserve focus in the current app and keep provider cards isolated when switching between them.

## Updating

Existing preferences, account profiles and startup choices are preserved. Open **General > Check for updates**, then choose **Install v0.3.0** when ready. The installed application downloads and verifies the update only after that click.

Windows x64 installer and portable ZIP are provided with **SHA256SUMS**. The installer remains unsigned, so Windows SmartScreen may show the existing reputation warning.
