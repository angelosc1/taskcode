# Taskcode 0.4.5

Working providers now show their usage pace around the spinning logo.

## Usage atom

- While Claude, Codex or another provider is working, small spheres orbit its logo in the taskbar indicator:
  - **2 spheres**: light usage. At this pace the quota lasts past the next reset.
  - **4 spheres**: medium usage. The quota runs out close to the reset.
  - **6 spheres**: heavy usage. The quota runs out before the reset.
- These are the same levels that set the logo's spin speed and the speed arrows in Details.
- Each sphere follows its own tilted path, neighbouring spheres run in opposite directions, and each leaves a comet tail in the provider color. The logo shrinks slightly so everything stays inside the indicator.
- With Windows animations turned off, the spheres stay still, so the count still shows the pace.
- Turn it off in **Appearance > Usage atom** to keep only the spinning logo. Your choice is kept across updates.

## Settings

- The settings window is slightly taller to fit the new switch.
- The Portuguese label for the time marker is shorter so it is no longer cut off.

Download **Taskcode-Setup-0.4.5-win-x64.exe** for installation or **Taskcode-0.4.5-win-x64.zip** for portable use. Existing users can update from **General > Check for updates**.

Windows 11 x64 and .NET Framework 4.8 are required. The installer remains unsigned; see the [installation guide](https://github.com/angelosc1/taskcode/blob/main/docs/INSTALL.md) for SmartScreen instructions.
