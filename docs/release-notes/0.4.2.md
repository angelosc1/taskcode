# Taskcode 0.4.2

Claude quota keeps loading through token renewals, and Taskcode starts quietly on the taskbar.

## Claude quota

- Fixed Claude percentages disappearing for up to an hour. When the Claude Code token expired, Taskcode sent it anyway; the usage service answers expired tokens with a one-hour rate limit, even after Claude Code has already renewed the token.
- Taskcode never sends an expired token. Shortly before expiry it briefly starts the official Claude Code CLI in the background so the CLI renews its own sign-in. No prompt is sent and nothing is used from your quota.
- A renewed token immediately clears any wait caused by the old one. A rejected token is re-read and retried once.
- While a check fails or is rate limited, the last Claude reading stays visible for up to an hour, as long as its period has not reset.

## Startup

- Opening Taskcode now shows only the taskbar indicator. Settings open on the first run after installation, when Taskcode is opened again while already running, or from its icon.

Download **Taskcode-Setup-0.4.2-win-x64.exe** for installation or **Taskcode-0.4.2-win-x64.zip** for portable use. Existing users can update from **General > Check for updates**.

Windows 11 x64 and .NET Framework 4.8 are required. The installer remains unsigned; see the [installation guide](https://github.com/angelosc1/taskcode/blob/main/docs/INSTALL.md) for SmartScreen instructions.
