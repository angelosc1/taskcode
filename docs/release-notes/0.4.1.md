# Taskcode 0.4.1

Claude quota stays visible: Taskcode now always reads the account you already use in Claude Code.

## Claude connection

- Fixed Claude percentages disappearing a few hours after connecting with **Sign in with Claude**. That separate Taskcode profile was never refreshed, so its session expired and the indicator showed `--`.
- Claude now has a single connection option, **Use existing CLI account**. Claude Code keeps that session refreshed while you use it.
- Existing installations switch automatically on update. No new sign-in is needed.

## Other providers

- Grok and OpenCode now say when a session has expired and how to renew it, instead of asking you to sign in from scratch.
- All other providers were reviewed; none use a separate profile that could expire unnoticed.

## Details

- Details cards use a new close button.

Download **Taskcode-Setup-0.4.1-win-x64.exe** for installation or **Taskcode-0.4.1-win-x64.zip** for portable use. Existing users can update from **General > Check for updates**.

Windows 11 x64 and .NET Framework 4.8 are required. The installer remains unsigned; see the [installation guide](https://github.com/angelosc1/taskcode/blob/main/docs/INSTALL.md) for SmartScreen instructions.
