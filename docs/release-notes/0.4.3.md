# Taskcode 0.4.3

The indicator stays on the taskbar, and the Details card stops flickering.

## Indicator

- Fixed the indicator disappearing and reappearing. It used to hide whenever a taskbar measurement was late, briefly failed, or the system tray changed size.
- It now stays in its last verified place for up to 15 seconds while the measurement recovers. When only the system tray resizes, such as when a tray icon appears, the indicator follows the new tray edge right away. It still never covers taskbar buttons.

## Details

- Fixed the card's border and logo flickering. The card was being fully redrawn every second.
- Hover Details no longer stop opening after brief indicator pauses or while the indicator scrolls. The card is brought to the front whenever it opens.

Download **Taskcode-Setup-0.4.3-win-x64.exe** for installation or **Taskcode-0.4.3-win-x64.zip** for portable use. Existing users can update from **General > Check for updates**.

Windows 11 x64 and .NET Framework 4.8 are required. The installer remains unsigned; see the [installation guide](https://github.com/angelosc1/taskcode/blob/main/docs/INSTALL.md) for SmartScreen instructions.
