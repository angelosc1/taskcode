Fixes a helper-update issue found during first-install testing.

- The installer now refreshes both the application's Claude bridge and the managed helper used by Claude Code hooks.
- Moving from a development copy or an earlier installation no longer leaves the active helper on an older build.
- Preferences, account profiles and the Windows startup choice are preserved.

**Install or update:** download `Taskcode-Setup-0.1.1-win-x64.exe`, or use **General > Check for updates > Install v0.1.1** in an installed copy.

[Installation guide](https://github.com/angelosc1/taskcode/blob/main/docs/INSTALL.md). Windows 11 x64 and .NET Framework 4.8 are required. This early release is unsigned; the initial taskbar compatibility limitations still apply.

Validation: the official 0.1.0-to-0.1.1 update was downloaded, SHA-256 verified and installed locally. Preferences, account selection and startup choice were preserved, and the managed helper matches the installed application helper. [Validation details](https://github.com/angelosc1/taskcode/blob/main/docs/VALIDATION.md).
